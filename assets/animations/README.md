# Motion kit

These SVG components use only SVG SMIL or local CSS—no JavaScript and no GIF assets.

| Asset | Effect | Intended use |
|---|---|---|
| `typing-cursor.svg` | Typing cursor | Terminal labels and short status lines. |
| `glow-orbit.svg` | Glow/orbit | Small AI or system-focus visual. |
| `hover-panel.svg` | Hover | Direct SVG contexts; retains a static fallback when embedded as an image. |
| `gradient-flow.svg` | Gradient flow | Divider or transition between major sections. |
| `pulse-beacon.svg` | Pulse | Small live-status indicator. |
| `floating-nodes.svg` | Floating | AI/system relationship illustration. |
| `neon-flicker.svg` | Neon flicker | One-off heading or footer accent. |

Keep only one or two motion assets visible in any README viewport. All assets use simple vector primitives and remain small so the profile stays responsive.
