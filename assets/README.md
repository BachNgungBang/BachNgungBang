# Assets

All presentation assets used by the root `README.md` belong here. Keep files small, named by purpose, and referenced with relative paths.

| Folder | Function |
|---|---|
| `images/` | Static raster images, screenshots, and original visual references. |
| `svg/` | Static, reusable vector diagrams and illustrations. |
| `icons/` | Small interface/social/technology icons with a consistent style. |
| `background/` | Subtle backgrounds, grids, textures, and decorative layers. |
| `animations/` | Lightweight animated SVG assets such as hero or footer effects. |
| `typing/` | Typing/terminal-line assets or their source configuration. |

Do not place generated GitHub statistics here; generated output needs a dedicated documented source when introduced.
